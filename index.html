About this App

This tool performs in-browser OCR using the following open-source libraries:

  • Tesseract.js: For the core OCR engine.
  • PDF.js (by Mozilla): To convert PDF pages into images.
  • Docx.js: To create and download .docx files.

All processing is done on your computer. No files or data are ever uploaded to a server.
